### デザイン面
1. 設計について
本サイトのフロントエンドは、大学の授業「ユーザビリティ工学」で学んだ知見を基に設計しました。設計において最も重視したのは、「誰もが直感的に操作できること」です。初めて利用するユーザーでも迷わず目的を達成できるよう、情報設計と視覚設計の両面から工夫を行いました。

2. UI設計について
UIは、シンプルで分かりやすい構成を意識しています。ボタンのラベルには短く具体的な表現を採用し、専門用語は使用していません。行動が直感的に伝わる言葉を用いることで、ユーザーが次に取るべき操作を自然に理解できる設計としています。これにより、判断にかかる時間を短縮し、スムーズな操作を実現しています。

3. 色の統一による役割の明確化
本サイトでは、色数を最小限に抑えたことに加えて、「同じ役割を持つ要素には同じ色を使用する」というルールを設けています。例えば、主要なアクションを実行するボタンはすべて同じ色で統一しています。
これにより、ボタンの色がページごとに変わらないため、学習コストが下がり、操作の予測可能性が高まります。また、視覚的な一貫性が保たれることで画面全体が整理され、重要な操作を素早く認識できる設計としています。

4. 情報構造と視線誘導
さらに、情報の整理と視線設計にも配慮しました。1画面につき1つの目的を明確にし、余白を確保しています。また、要素を中央に配置することで視線移動を最小限に抑え、ユーザーが迷うことなくスムーズに目的のページへ移動できる構造としました。

5. レスポンシブ設計
画面サイズが変化してもレイアウトが崩れない構造を実現しました。PCとスマートフォンどちらで開いてもレイアウトが崩れない設計になっています。
